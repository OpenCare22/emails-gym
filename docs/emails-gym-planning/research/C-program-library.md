# Deliverable C — Complete Original Program Library

Seven original starter programs, each eight weeks, fully enumerated in `program-library.json`. This document shows the executable session templates and every week’s modification policy. **Program data (expanded_weeks) contains the literal workout prescriptions for every week**, so developers should import the JSON rather than parse tables here.

General safety: intended for generally healthy adults; every session requires appropriate warm-ups and pain-free technique. “RIR” = perceived reps in reserve. Cardio RPE 7–8 = hard but controlled, not maximal.

5-10 minutes progressively easier-to-moderate movement; finish with easy cooldown.

5-10 minutes progressively easier-to-moderate movement; finish with easy cooldown.

- **Cardio:** bike/elliptical, baseline 28 min, interval; 8 min easy + 4×(2 min RPE 7/3 min easy) + cool down; avoid maximal sprinting

### Long easy aerobic — suggested day 6
5-10 minutes progressively easier-to-moderate movement; finish with easy cooldown.
