# T-005: Remove upstream project overhead

## Goal
Delete the files that only matter to the upstream project's own process (GitLab mirror, CLA,
Renovate, roadmap, iOS CI, image publishing) so the fork's GitHub Actions only run the tests.

## Context
- Delete: `.gitlab-ci.yml`, `.gitlab/`, `.github/workflows/mirror.yml`, `.github/workflows/ios.yml`,
  `.github/workflows/cla.yml`, `.github/workflows/cla-issue.yml`, `renovate.json`, `CLA.md`,
  `ROADMAP.md`.
- `.github/workflows/docker-publish.yml` and `release-check.yml`: read them. Delete them if they
  publish to upstream's registry or check upstream's release process; keep them if they are useful
  for a self-hosted fork, and say which and why.
- Keep `.github/workflows/test.yml` and `audit.yml`.
- Other references: `CONTRIBUTING.md`, `README.md`, `CLAUDE.md`, `.github/` issue/PR templates
  that mention the CLA, GitLab or the mirror.

## Allowed files
- The files listed above
- .github/** (templates and the workflows named above)
- CONTRIBUTING.md, README.md, CLAUDE.md, docs/ARCHITECTURE.md, scripts/README.md (references only)

## Forbidden files
Everything else. Keep `LICENSE`, `NOTICE.md`, `SECURITY.md`, `CHANGELOG.md`, `.github/workflows/test.yml`.

## Rules
Follow AGENTS.md. In CLAUDE.md, replace the GitLab mirror paragraph with one line saying this
is a fork at github.com/OpenCare22/emails-gym of github.com/DuarteSantos8/openGym.

## Acceptance
- All checks in AGENTS.md pass.
- `grep -rniE "gitlab|renovate|\bCLA\b" --exclude-dir=node_modules .` finds nothing you can't justify.
- In your result: what you deleted, what you kept and why, and the check results.

## Out of scope
Deployment dirs (T-004), mcp (T-006), rewriting the README.
