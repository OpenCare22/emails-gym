# T-029: Friends 2: the Friends screen, joining by link, sharing choices and leaderboards

## Goal
PLAN.md Phase 7 item 3 and the Friends screen of the design handoff (§4C). Needs T-028.

### Server: `GET /api/social/leaderboard?groupId&metric&range` (in `api/social/routes.js`)
- Caller must be a member. metric: `workouts` (range week | month | all), `streak` (current weeks,
  with best as a second value), `volume` (week | month, kg, shown in the viewer's unit by the app),
  `prs` (month), `steps` (week), `activeMinutes` (week), `strength` (`lift`: squat | bench | deadlift,
  ratio to body weight, two decimals).
- Rows only for members who share that metric with **this** group; the caller's own row always
  (marked `self`, with `shared: false` when they don't share it, so the app can say "Only you see
  this"). Ranks with ties sharing a rank (1, 1, 3), then name. `{ metric, range, label, rows: [{ uid,
  name, value, second?, rank, self }] }`. Tests in `api/test/social.test.js`.

### App
- `frontend/src/lib/fork-flags.js`: `FRIENDS_API = true`.
- `frontend/src/lib/social.js` (+ test): API calls and a small zustand store like `lib/google-health.js`.
- `views/Friends.jsx`: replace the placeholder `useLeaderboard` with the real one. Layout per the
  handoff: title "Friends", a group switcher when in more than one group, the segmented control
  (This week · Streaks · All time) plus a metric picker for the other metrics, the metric explained
  in plain words under it ("Workouts completed this week"), ranked rows (`LeaderboardRow`, the user's
  own row with the quiet highlight, a small crown for rank 1 only), ties shown as equal ranks.
  Empty states: no group yet ("Start a group" + "Join with a link" ), a group with only you
  ("Invite friends" with the share sheet), a metric nobody shares ("Nobody shares this yet").
  Never placeholder people.
- Invite: the owner's "Invite friends" shares `https://<this server>/#/join/<code>` with the Web
  Share API (`navigator.share`, falling back to copy), with the expiry date.
- `#/join/:code` route (`App.jsx`): signed in → a sheet "Join <group>?" with the sharing choices
  (switches for each metric, Workouts and Streak preselected, the others off, one line each on what
  others will see) and Join; signed out → the sign-in screen first, then back to the join sheet
  (keep the code in sessionStorage).
- Group settings sheet (from the Friends header): rename (owner), invite link on/off/new (owner),
  members with Remove (owner), your sharing switches, "Receive nudges", Leave group (confirm).
- 44 px targets, text through `t()`, plain, no em dashes, tokens and components already used.
- Tests: the screen states (no group, alone, leaderboard with self and tie, metric nobody shares),
  the join sheet, the settings sheet's sharing switches.
