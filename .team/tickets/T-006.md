# T-006: Remove the MCP server

## Goal
Delete `mcp/`, the optional stdio MCP server, and everything that only exists for it.

## Context
- `mcp/` has its own package.json, tests and README. It imports
  `frontend/src/lib/log-workout.js`; check whether anything else still uses that file before
  touching it (if something does, keep it).
- CI: `.github/workflows/test.yml` has an `mcp` path filter and job.
- Mentions in `CLAUDE.md`, `docs/ARCHITECTURE.md`, `docs/README.md`, `README.md`,
  `scripts/README.md`, `scripts/pair.mjs` (or similar pairing helpers used only by mcp).
- The in-app AI Coach (`api/coach/`, `frontend` coach views) is a different feature and stays.

## Allowed files
- mcp/**
- frontend/src/lib/log-workout*.js
- scripts/**
- package.json
- package-lock.json
- .github/workflows/test.yml
- CLAUDE.md
- AGENTS.md
- docs/ARCHITECTURE.md
- docs/README.md
- README.md

Notes on allowed files:
- Delete `mcp/**`.
- `log-workout*.js`: only if nothing outside mcp uses it.
- `scripts/**`: only scripts used by mcp alone, and scripts/README.md.
- `AGENTS.md`: drop `mcp` from the symlink loop.

## Forbidden files
Everything else, `api/coach/**` in particular.

## Rules
Follow AGENTS.md.

## Acceptance
- All checks in AGENTS.md pass.
- `grep -rn "mcp" --exclude-dir=node_modules . | grep -vi "mcp_\|camp"` finds nothing you can't justify.
- In your result: what you deleted and the check results.

## Out of scope
Anything about the AI Coach.
