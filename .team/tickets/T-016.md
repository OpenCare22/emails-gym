# T-016: Programs: browse, see the detail, start one

## Goal
Route A of the master plan (`docs/emails-gym-planning/CLAUDE_CODE_MASTER_PLAN.md` §2): browse the
program library built in T-015 (`frontend/src/lib/library-data.js`, helpers in `lib/library.js`),
open one, and start it. Starting turns it into the user's own routines and programme, so the
existing workout screen, progression, history, Home's Today and the reminders all work unchanged.
Needs T-014 (programme weeks with `sets` and `rir`) and T-015 merged.

- **Entry:** on the Routines view (`views/Plan.jsx`, under the Workouts tab), a "Programs" row near
  the top: "Ready-made plans, 2 to 4 days a week". Routes `/programs` and `/programs/:id` in
  `App.jsx`. Load the library data with a dynamic `import()` so it isn't in the main bundle.
- **List (`views/Programs.jsx`):** filter chips for goal, days per week and level (the existing chip
  style); cards with title, goal, level, days, the minutes range ("35 to 50 min"), weeks, main
  equipment. Every `isVisible(program, review)` program (all but retired), for everyone. A program that isn't
  approved shows a quiet "Not reviewed by a coach yet" badge. Empty state when the filters
  match nothing.
- **Detail (`views/ProgramDetail.jsx`):** the approach, the sessions (exercise names, sets × reps or
  seconds, RIR, rest), the weeks as "Week 1: 1 set per exercise, RIR 4" lines, equipment, the minutes
  range, and one plain line: "Based on published training research and reviewed by a certified
  coach." for approved programs, or "Based on published training research. Not reviewed by a coach yet."
  otherwise. A program with blockers (T-015) lists them in plain words above Start, e.g. "The
  interval sessions are longer than the time shown". No
  medical claims.
- **Start program** (primary) and **Copy to my routines** (secondary):
  - Both create one routine per template (`S.routines`, new ids, name = template name, slots from
    the items: reps range → `reps`/`repsMin`, rest, `side`, timed items `mode: 'time'` with `sec` =
    the range's low end, cardio items `mode: 'cardio'` with `min`) and a programme (`S.programmes`)
    with `weeks` from the plan's sets and RIR per slot (T-014's fields), the schedule on weekdays
    from the templates' `day`, and `src: { lib: program.id, version: program.version }`.
    The library data itself is never changed; the copy is the user's to edit.
  - Start then runs it through the existing start path in `lib/programmes.js` (which keeps the
    user's previous plan in `saved` and puts it back when the programme ends). If a programme is
    already running, ask first (the sheet the Programmes screen already uses for that, if there is
    one; otherwise a confirm sheet: "Stop <name> and start <new>?").
  - Afterwards go to the programme's screen (`/plan/prog/:id`) with a toast "Started <name>".
- Every new string through `t()`, plain, no em dashes; 44 px targets; existing tokens and components.
