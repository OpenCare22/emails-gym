# T-004: Remove the other deployment options and upstream's website

## Goal
This fork is self-hosted with Docker Compose only. Delete Helm, Kubernetes, Nix, Cloudflare,
fastlane and upstream's own website (opengym.ch), and everything that only exists to serve them.

## Context
- Directories: `helm/`, `kubernetes/`, `contrib/nix/`, `cloudflare/`, `website/`, `fastlane/`.
- `scripts/build-api-docs.mjs` writes `website/api.html` and CI runs it with `--check`. Keep the
  API docs check working: point it at `docs/api.html` (or similar) instead, or keep only its
  validation part. Say which.
- `api/test/k8s-web-port.test.js` and maybe other tests read Kubernetes/Helm files.
- `.github/workflows/pages.yml` deploys the website.
- Docs: `docs/NIX.md`, `docs/SELF_HOSTING_KUBERNETES.md`, plus mentions in `docs/README.md`,
  `docs/SELF_HOSTING*.md`, `README.md`, `CLAUDE.md`, `docs/ARCHITECTURE.md`, `scripts/README.md`.
