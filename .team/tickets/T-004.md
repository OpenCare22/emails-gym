# T-004: Remove the other deployment options and upstream's website

## Goal
This fork is self-hosted with Docker Compose only. Delete Helm, Kubernetes, Nix, Cloudflare,
fastlane and upstream's own website (opengym.ch), and everything that only exists to serve them.

## Context
- Directories: `helm/`, `kubernetes/`, `contrib/nix/`, `cloudflare/`, `website/`, `fastlane/`.
- `scripts/build-api-docs.mjs` writes `website/api.html` and CI runs it with `--check`. Keep the
  API docs check working: point it at `docs/api.html` (or similar) instead, or keep only its
  validation part. Say which.
- `api/test/k8s-web-port.test.js` and maybe other tests read Kubernetes/Helm files.
- `.github/workflows/pages.yml` deploys the website.
- Docs: `docs/NIX.md`, `docs/SELF_HOSTING_KUBERNETES.md`, plus mentions in `docs/README.md`,
  `docs/SELF_HOSTING*.md`, `README.md`, `CLAUDE.md`, `docs/ARCHITECTURE.md`, `scripts/README.md`.

## Allowed files
- helm/**, kubernetes/**, contrib/**, cloudflare/**, website/**, fastlane/** (delete)
- scripts/** that only serve those, scripts/build-api-docs.mjs, scripts/README.md
- api/test/** that read the deleted files
- .github/workflows/pages.yml (delete), .github/workflows/test.yml (filters and steps that mention them)
- docs/NIX.md, docs/SELF_HOSTING_KUBERNETES.md (delete), docs/README.md, docs/SELF_HOSTING*.md,
  README.md, CLAUDE.md, docs/ARCHITECTURE.md, .gitignore, .dockerignore

## Forbidden files
Everything else. Keep `docker-compose.yml`, `web/`, `api/Dockerfile`, `docs/MOBILE.md`,
`docs/APP_STORES.md`.

## Rules
Follow AGENTS.md. In README.md only remove dead links and sections; the fork's README rewrite comes later.

## Acceptance
- All checks in AGENTS.md pass, with `build-api-docs.mjs --check` still meaningful.
- `docker compose build` still works (if you can't run Docker, say so).
- `grep -rnE "helm/|kubernetes/|contrib/nix|cloudflare/|website/|fastlane" --exclude-dir=node_modules .`
  finds nothing you can't justify.
- In your result: what you deleted, where the API docs now go, and the check results.

## Out of scope
GitLab, CLA and other workflow files (T-005), the mcp server (T-006).
