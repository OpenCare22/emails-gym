# T-012: Swipe a workout in History to delete it, with Undo

## Goal
Deleting a workout from History already exists (tap the workout → its options → Delete workout,
`frontend/src/sheets.jsx` around `deleteWorkout`), but nobody finds it. Make it obvious: swipe a
History row toward the start of the line to delete it, the way sets and Plan's routines already
swipe, and offer **Undo** on the toast instead of a confirm sheet. The options menu's Delete
(with its confirm) stays as it is.

## Context
- `frontend/src/components/SwipeRow.jsx` + `lib/use-swipe-row.js`: the swipe. A row without
  `onCopy` is delete-only (Plan uses it that way: `views/Plan.jsx`, `deleteLabel`,
  `deleteIcon`). Read the comments at the top of SwipeRow.jsx: panes, accessibility, opaque row.
- History rows: `views/History.jsx` renders `WorkoutRow` (`sheets.jsx`) per workout.
- The existing delete: `s.workouts = s.workouts.filter(x => !sameWorkout(x, w))`, with
  `mediaGoesToo(...)` in the confirm text (a workout's photos/videos go with it).
- **Undo must survive sync.** A deleted item stays deleted across devices (`lib/sync-merge.js`
  and its stamps; `api/sync-stamps.js` is its server twin). Putting the same workout back must not
  be undone by the deletion on the next sync or merge. Find how the app already restores a
  deleted thing with Undo elsewhere (e.g. removing a set in a workout, `removeSet` /
  `undoDeleteSet` in `views/Workout.jsx`, or Plan's routine delete) and follow the same pattern.
  Put the delete/restore logic in a pure helper in `frontend/src/lib/` with a test, including a
  sync-merge test: delete, undo, then merge with a copy from before the delete keeps the workout.
- Media: deleting must not lose the workout's photos/videos if Undo is tapped. Check what
  `localMediaGc` (`lib/media-sync.js`) collects and when; if it could run before the toast is gone,
  make sure an undone workout's media is still there (test it).
- Keyboard and screen-reader users keep the options menu way; the swipe pane follows SwipeRow's
  existing accessibility rules.
