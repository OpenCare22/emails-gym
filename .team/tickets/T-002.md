# T-002: Remove Garmin and Zepp watch support

## Goal
Nobody using this fork has a Garmin or Zepp watch. Delete both watch apps and every Garmin/Zepp
piece of the web app, keeping the Apple Watch path untouched.

## Context
- `frontend/garmin/` (Connect IQ app) and `watch-zepp/` (Zepp OS app) at the repo root.
- `frontend/src/lib/garmin-snapshot.js` (+ test), `lib/watch-sync.garmin.test.js`,
  `views/ZeppSettings.jsx`, `views/Modules.garmin.test.jsx`, plus Garmin/Zepp rows in Settings
  and in the modules list (`docs/MODULES.md`).
- The Apple Watch uses the same watch protocol (`lib/watch-sync.js`, `api/watch-relay.js`,
  `WatchSettings.jsx`): keep those, removing only Garmin/Zepp branches that are clearly separable.
- CI may have Garmin/Zepp jobs or filters in `.github/workflows/test.yml`; scripts may live in
  `scripts/`.

Notes on allowed files:
- Delete: `frontend/garmin/**`, `watch-zepp/**`, `garmin-snapshot*.js`, `watch-sync.garmin.test.js`,
  `ZeppSettings.jsx`, `Modules.garmin.test.jsx`, `docs/GARMIN.md`, `docs/ZEPP_OS.md`.
- `watch-sync*`, `watch-relay*`, `modules*`, Settings, Modules: Garmin/Zepp branches and rows only.
  `lib/watch-relay.js` and `api/watch-relay.js` stay (the Apple Watch protocol); remove only
  Zepp-specific parts if clearly separable, and say which.
- `api/**`: only Garmin/Zepp-only code paths (say which), keeping `openapi.yaml` in step.
- `scripts/**`: only scripts that build or check Garmin/Zepp, and scripts/README.md.
- `frontend/src/locales/*.js`: only to delete keys that are no longer used anywhere.

## Forbidden files
Everything else, in particular `frontend/ios/**`, `WatchSettings.jsx`, `api/watch-relay.js`,
`lib/watch-relay.js`, `catalogue/**`.

## Rules
Follow AGENTS.md. Check every import before deleting a file.

## Acceptance
- All checks in AGENTS.md pass.
- `grep -rniE "garmin|zepp" --exclude-dir=node_modules frontend/src api scripts .github` finds
  nothing you can't justify in the result.
- In your result: what you deleted, what you kept and why, and the check results.

## Out of scope
Android/Wear OS (T-001), locales (T-003).
