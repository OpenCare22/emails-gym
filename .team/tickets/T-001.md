# T-001: Remove the Android app, Wear OS and Health Connect

## Goal
Nobody using this fork has Android. Delete the Android Capacitor shell (including the Wear OS
watch app) and the Android-only Health Connect code, and take Android out of Capacitor's config
and CI, without changing anything an iPhone, the PWA or the Apple Watch uses.

## Context
- `frontend/android/` holds the Capacitor shell and `frontend/android/wear/` (Wear OS).
- `frontend/capacitor.config.json` has an `"android"` block.
- `frontend/src/lib/health-connect.js` (+ test) is the Health Connect bridge; `lib/health-sync.js`
  has an Android branch next to the Apple Health one; Settings has Health Connect UI
  (`views/Settings.jsx`, `Settings.health.test.jsx`).
- `lib/channel.js` distinguishes APK and store builds; `scripts/android/` has release and F-Droid
  scripts; `.github/workflows/test.yml` has an `android` job and path filter.
- `lib/watch-sync.js` serves both the Apple Watch and Wear OS: drop only Wear OS-specific
  branches if they are clearly separable, otherwise leave watch-sync alone and say so.

Notes on allowed files:
- Delete: `frontend/android/**`, `scripts/android/**`, `docs/WEAR_OS.md`.
- `frontend/capacitor.config.json`: remove the android block only.
- `health-connect.js` is shared with Apple Health (`plannedType` etc.): keep it, drop only
  Android-only tables and tests.
- `health-sync*`, `channel*`, `watch-sync*`, Settings files: Android / Health Connect / Wear OS
  branches and UI only.
- Tests that read files under `frontend/android/` (`android-*.test.js`, `system-bars`,
  `native-keyboard`, `rest-alert.native`, `rest-sounds`, `voice-strings`, `app-icons`,
  `health-connect`): delete the Android-only tests or assertions, keep the iOS/web ones.
- `garmin-snapshot.test.js` reads `android/wear/src/test/resources/snapshot.json`, the shared watch
  fixture: move that fixture to `frontend/src/lib/__fixtures__/watch-snapshot.json` and point the
  test at it (T-002 deletes Garmin later). Check `frontend/ios` doesn't read the old path.
- `frontend/src/locales/*.js`: only to delete keys that are no longer used anywhere.

## Forbidden files
Everything else, in particular `frontend/ios/**`, `AppleHealthPlugin.swift`, `lib/health-read.js`,
`lib/heart-rate.js`, `lib/watch-relay.js`, `api/watch-relay.js`, `WatchSettings.jsx`,
`catalogue/**`.

## Rules
Follow AGENTS.md. Check every import before deleting a file. Leave the `MOBILE` code paths alone.
If removing `@capacitor/android` from package.json needs a lockfile change, regenerate it with
`npm install --package-lock-only` in `frontend/` and mention it.
