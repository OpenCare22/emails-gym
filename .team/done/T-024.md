# T-024: Heart rate on gym sessions, from Google Health

## Goal
PLAN.md Phase 4 item 5: a logged gym session gets the Fitbit's heart rate when their times overlap,
per set and for the whole session, the way the Apple Watch and Apple Health already fill it.

- **Server** (`api/health/`): `GET /api/google-health/heart-rate?start=<ISO>&end=<ISO>` for the signed-in
  profile. The window may be at most 6 hours and must be within the last 120 days; else 400.
  Reads the Google Health `heart-rate` data type with
  `filter=heart_rate.sample_time.physical_time >= "<start>" AND heart_rate.sample_time.physical_time < "<end>"`,
  `pageSize=10000`, following `nextPageToken` (google.js `list`). Field names (from Google's
  discovery doc, verified): a point is `{ heartRate: { beatsPerMinute: "<string>", sampleTime:
  { physicalTime: "<RFC3339>" } } }`. Answers `{ samples: [{ t: <ms>, bpm: <int> }] }`, sorted.
  Uses the same access-token refresh and error codes as `syncNow` (409 reconnect, 404 not connected).
  Not cached on disk. Add it to `api/openapi.yaml` (tag health) and a test in
  `api/test/health-google.test.js` with the fake Google (window too long, filter string, paging).
- **App** (`frontend/src/lib/google-health.js`): `fillWorkoutHeartRate(S, getSamples, { now, tried })`:
  for finished workouts (`S.workouts`) from the last 14 days with a `start` and `end` and no session
  `hr` yet, at most 5 per call, newest first, skipping ids in `tried`: fetch samples for
  [start - 2 min, end + 2 min] and apply the existing `hrFromSamples(w, samples)` from
  `lib/heart-rate.js` with source `'gh'` (Google Health). Read `lib/heart-rate.js` first: it only
  fills sets that have no reading, and the session's `hr` gets `src`. Add `'gh'` wherever a source
  is named for display ("Fitbit"). Returns the ids it tried. Called after a successful `load()` in
  the `useGoogleHealth` store, writing through `useStore.getState().update`; the tried ids are kept
  in localStorage so a workout without samples isn't asked for again.
- Tests: the pure function with a fake `getSamples` (fills a 40-minute session, never overwrites a
  watch reading, skips old workouts and ones already tried, at most 5).
