# T-025: "Import this run?" for workouts the Fitbit detected

## Goal
PLAN.md Phase 4 item 5 and Phase 6 ("link a cardio block to the Fitbit activity"): runs, walks,
rides and other sessions the Fitbit detected show on Home as a card to import, never added silently.

- Data: `useGoogleHealth().info.data.exercise` (see `frontend/src/lib/google-health.js` and
  `api/health/data.js`): `{ id, type, name, start, end, d, minutes, avgHr, kcal, distanceKm, steps }`.
- Pure helper in `frontend/src/lib/google-health.js` (+ tests): `importableExercises(S, exercises,
  { today })` → the ones from the last 7 days that are not dismissed (`S.ghDismissed`, an array of
  ids), not already imported (a workout with `src: { gh: id }`), and do not overlap a logged workout
  by more than half their duration (a gym session the watch also logged as "weights" is not a run
  to import). Newest first, at most 3. `FREE_WEIGHTS`, `FUNCTIONAL_STRENGTH_TRAINING` and
  `CIRCUIT_TRAINING` types are never offered.
- `workoutFromExercise(e, S)` → a finished workout for `S.workouts`: `{ id, d, start, end, name,
  entries: [{ id: <catalogue id>, sets: [{ min, speed, done: true, at }] }], src: { gh: e.id },
  hr: { avg: e.avgHr, src: 'gh', n: 0 } (only when avgHr) }`, speed in the profile's speed unit from
  distance and duration (`lib/speed.js`), 0 when there's no distance. Read `lib/finish-workout.js`
  `buildCompletedWorkout` for the exact workout shape and copy it, don't invent fields. Map the type
  to a catalogue id: RUNNING '0685', WALKING '2258', HIKING '2258', BIKING '5214', ELLIPTICAL '2192',
  ROWING '1161' (rowing machine), SWIMMING '6944', anything else '2258' with the Fitbit's own name as
  the workout name.
- `S.ghDismissed` is a new top-level array in the store's defaults (`store/useStore.js`), capped at
  200 ids (oldest dropped). It syncs as one setting.
- Home (`views/Home.jsx`): above the metric cards, one card per importable exercise: "From your
  Fitbit: Run, 31 min, 5.2 km, avg 151 bpm" with **Import** (adds the workout, toast "Added to your
  history", the card goes) and **Dismiss** (adds the id to `S.ghDismissed`). 44 px targets, the
  existing card style.
- Tests: the helpers (window, overlap, dismissed, already imported, cap, the workout shape, speed
  in km/h and mph) and a Home render test with the store mocked (Import adds one workout; Dismiss).
