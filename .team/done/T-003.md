# T-003: English only

## Goal
Remove every translation except English. The app shows English everywhere, the language picker
disappears (or shows English only if removing it is invasive), and the locale tooling still runs.

## Context
- `frontend/src/locales/*.js`: one pack per language, keyed by the English string. English is the
  key itself, so there is no `en.js`. `lib/i18n.js` / `i18n-core.js` load the packs.
- `frontend/scripts/check-locales.mjs`, `check-source-strings.mjs` and their tests; pt-BR has a
  fingerprint test (`frontend/scripts/pt-br-inheritance-fingerprint.mjs`).
- Catalogue translations: `catalogue/i18n/*.json`, built by `scripts/catalogue/build.mjs` into
  generated files (`exercise-names/`, `exercise-desc/`, `instr/`). Trim them to English only if the
  build supports it cleanly; if it doesn't, leave the catalogue translations and say why.
- `scripts/de-name-rules.mjs`, `scripts/catalogue/validate.mjs`, `frontend/scripts/pdf/render-samples.mjs`
  also reference locales. `.env.example` has a default language setting.
- Users who had picked another language must land on English without errors.
- Left over from T-002: the Watch module's description reads "Apple Watch / Wear OS watch" in
  `frontend/src/lib/modules.js` (`desc`) and `frontend/src/lib/modules-copy.js`. Once the packs
  are gone, make both say "Log sets from your wrist on an Apple Watch."

Notes on allowed files:
- Delete the non-English packs in `frontend/src/locales/` and `catalogue/i18n/`.
- `frontend/src/views/**`, `frontend/src/components/**`: the language picker and its tests only.
- `frontend/src/lib/**/*.test.js`: only tests that loop over all locales.
- Generated catalogue outputs (`exercises-data.js`, `instr/`, `exercise-names/`, `exercise-desc/`):
  only by rerunning `node scripts/catalogue/build.mjs`, never by hand.
- `api/**`: only server-side language handling (default language env var, push text), with
  `openapi.yaml` if a route changes.
- `.env.example`, `docs/SELF_HOSTING.md`: the default language section only.

## Forbidden files
Everything else, `catalogue/media/**` and `catalogue/exercises/**` in particular.

## Rules
Follow AGENTS.md. Never edit generated files by hand: rebuild them with the script.

## Acceptance
- sh scripts/fork/check.sh

## Report
- `check-locales.mjs`, `check-source-strings.mjs --strict` and `catalogue/build.mjs --check` are
  adapted to English only, not deleted.
- A saved state with `lang: 'de'` (or whatever the field is) loads in English; add a test for it.
- In your result: what you removed, how much smaller the frontend build got (compare `dist/` sizes
  before and after), and the check results.

## Out of scope
Changing any English wording.
